## Aero7 Beta 2 — under development

Aero7 is an independent, open-source Linux distribution that brings the calm,
glassy desktop spirit of the late 2000s to a modern Arch Linux, Plasma 6 and
Wayland foundation. Beta 2 joins the dedicated Aero7 Desktop, a Dolphin-based
File Explorer, familiar system tools, Desktop Gadgets and a guided installer
into one consistent experience from setup to login.

## Project repositories

| Repository | Purpose |
| --- | --- |
| [**aero7**](https://github.com/aero7-open-project/aero7) | Distribution, ISO builder, graphical installer, OOBE, release documentation and handbook |

## Contributing

Aero7 welcomes focused bug reports, tested fixes, translations, packaging work
and verified application integrations. Choose the repository responsible for
the component, read its documentation and open a focused pull request with the
exact test environment and results. Third-party code and artwork must include
their origin and redistribution license; do not submit proprietary Microsoft
assets.
